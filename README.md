# ИИ-помощник для работы с кодовой базой 1С

Локальный ассистент: отвечает на вопросы по коду конфигурации 1С, пишет документацию по единому шаблону, учится на обратной связи главного разработчика. Данные не покидают контур: LLM и эмбеддинги работают через Ollama.

## Состав

- MySQL: модули, процедуры, граф вызовов, документация с версиями, обратная связь
- Qdrant: векторный индекс процедур
- Ollama: bge-m3 (эмбеддинги) и qwen2.5-coder (ответы и документация)
- FastAPI: backend с REST API
- Streamlit: веб-интерфейс

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и замените значения в угловых скобках на свои пароли.
2. Установите Ollama и скачайте модели:

```
ollama pull bge-m3
ollama pull qwen2.5-coder:7b
```

3. Поднимите базы:

```
docker compose up -d
```

4. Установите зависимости:

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

На Linux и macOS активация: `source venv/bin/activate`.

5. Проверьте парсер на демо-конфигурации (из папки `backend`):

```
python check_parser.py
```

6. Загрузите код, постройте индекс и сгенерируйте документацию:

```
python -m app.cli load
python -m app.cli index
python -m app.cli docs
```

Команда `python -m app.cli all` выполняет все три шага. Путь к другой выгрузке можно передать вторым аргументом: `python -m app.cli all D:\path\to\config`.

7. Запустите API (из папки `backend`):

```
uvicorn app.main:app --reload
```

8. Запустите интерфейс (из папки `ui`, в другом терминале):

```
streamlit run app.py
```

Интерфейс: http://localhost:8501, документация API: http://localhost:8000/docs.

## Своя конфигурация

Выгрузите конфигурацию в файлы (Конфигуратор: Конфигурация, Выгрузить конфигурацию в файлы; или 1C:EDT), положите в `data/config_src` и укажите в `.env`:

```
CONFIG_SRC=data/config_src
```

## Ежедневное обновление

```
git -C data/config_src pull
cd backend
python -m app.cli all
```

Пересчитываются только процедуры с изменившимся хэшем кода: переиндексация и документация обновляются точечно. Эту команду можно повесить на `post-merge` hook или шаг CI.

## Цикл обратной связи

Кнопка «Неверно» с комментарием главного разработчика сохраняет запись в таблицу `feedback` и в фоне перегенерирует документацию по процедурам из ответа, добавляя комментарий в промпт. Новая версия документации попадает в контекст следующих ответов. Старые версии остаются в таблице `docs`.

## Ограничения прототипа

- Парсер основан на регулярных выражениях. Для сложных случаев его можно заменить на BSL Language Server или tree-sitter-bsl.
- Граф вызовов строится по совпадению имён, при одноимённых процедурах в разных модулях связь строится со всеми.
- Удалённые процедуры исчезают из MySQL, но их векторы остаются в Qdrant. Агент их игнорирует, при необходимости коллекцию можно пересоздать.
- Каскадная перегенерация документации вызывающих процедур не реализована.
